Kendi dili

OpenSharp

Uygulama yazmak için tasarlanmış küçük bir dil. Sözcüksel çözümleyici, ayrıştırıcı ve ağaç yürüyen yorumlayıcı — hepsi depoda, 2.000 satırın altında.

  • state ile tanımlanan değişken değişince arayüz kendiliğinden yenilenir
  • Büyük harfle başlayan çağrılar birer arayüz bileşenidir
  • Kapanışlar, listeler, sözlükler, metin araya yerleştirme
  • Dosya sistemi, kalıcı depo ve sistem çağrıları
  • Studio’da Kur deyince gerçek bir uygulamaya dönüşür
Studio’yu aç 
app {
  name: "Yapılacaklar"
  icon: "check"
  tint: ["#30d158", "#1a9e45"]
}

state items = store_get("items", [])
state draft = ""

fn addItem() {
  if len(trim(draft)) == 0 { return }
  push(items, { text: draft, done: false })
  store_set("items", items)
  draft = ""
}

view {
  VStack(spacing: 12, padding: 16) {
    HStack(spacing: 8) {
      TextField(draft, bind: "draft", grow: true)
      Button("Ekle", variant: "primary", onClick: addItem)
    }
    for i, it in items {
      Checkbox(it.text, value: it.done)
    }
  }
}
Kendi tarayıcısı

OpenBrow

Sekmeler, akıllı adres çubuğu, yer imleri, geçmiş, indirilenler, gizli gezinti, sayfada arama, yakınlaştırma — ve kendi sayfa motoru.

Dahili openos:// sayfaları iframe olmadan doğrudan OpenOS bileşenleriyle çizilir. Web sayfaları OpenBrow Proxy üzerinden alınır: çerçeveleme engelleri kalkar ve sayfaya OpenOS kimliği enjekte edilir. Sayfa kendisini tarayıcı içinde tarayıcıda değil, OpenOS üzerinde çalışan OpenBrow’da sanır.

Makine dostu

Yapay zekâ ajanları için tasarlandı

OpenOS yalnızca insanlar için değil. window.OpenOS altındaki API belgelenmiştir, izinlerle korunur ve her çağrı Ajan Merkezi’nde canlı olarak günlüklenir.

  • Kendini anlatan yetenek bildirimi: await OpenOS.describe()
  • Uygulama açma/kapatma, pencere düzeni, dosya işlemleri
  • Kabuk komutu ve OpenSharp betiği çalıştırma
  • Sistemin o anki tam durumu: OpenOS.snapshot()
// ajan konsolundan
await OpenOS.describe()
OpenOS.openApp("terminal")
await OpenOS.exec("ls ~/Projeler")
OpenOS.fs.write("~/Masaüstü/a.txt", "selam")

// kendi uygulamasını yazıp kurar
await OpenOS.runScript(`
app { name: "Ajan Paneli" icon: "robot" }
state n = 0
view {
  VStack(spacing: 12, padding: 20) {
    Label("Sayaç: " + n, style: "title")
    Button("Artır", onClick: fn() { n = n + 1 })
  }
}`)

OpenOS.arrangeWindows("tile")
